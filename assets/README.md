# Repository artwork

`lunar-lander-social.jpg` is the README hero and GitHub social preview image:
1280 × 640 pixels, opaque JPEG. It is promotional concept art, not a gameplay
screenshot.

To set the repository's social preview, open **Settings → General → Social
preview → Edit → Upload an image** and select this JPEG. Linking it from the
README does not set the social preview automatically. GitHub recommends
1280 × 640 pixels and requires an image under 1 MB; see
[GitHub's social preview documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

## Generation

Created with the built-in image generation tool, then resized proportionally
from 1774 × 887 to 1280 × 640 and exported as JPEG at quality 95 for delivery.
The art direction follows [the project design](../docs/design.md): indigo sky,
slate terrain, gold lander, cyan landing lights, and amber exhaust.

Final generation prompt:

```text
Use case: ads-marketing
Asset type: GitHub repository social banner and README hero, opaque landscape image, exactly 1280 x 640 pixels (2:1 aspect ratio).
Primary request: Create a polished, distinctive banner for "Lunar Lander", a precision flying game for NetBBS rendered in an ANSI terminal.
Scene/backdrop: a near-black indigo lunar sky with sparse fine stars and a small distant Earth, layered slate-blue angular mountain silhouettes, a rugged cratered lunar foreground. A small warm gold lunar lander descends toward a level landing pad marked by cyan lights. Short amber exhaust, delicately illuminated lunar dust.
Style/medium: exceptionally crafted retro computer game key art, crisp pixel art with stepped half-block-like terrain and restrained luminous terminal colors; cinematic scale and strong graphic composition. A deliberate pixel grid, no fuzzy painterly surfaces or generic sci-fi photorealism.
Composition/framing: wide 2:1 canvas; a large beautifully kerned two-line "LUNAR" / "LANDER" title anchors the left half, lander and cyan landing pad on the right half, mountains along the lower third. Keep all important text and objects generously inset from every edge. Strong thumbnail legibility and generous negative space. Layered terrain adds depth without busy texture.
Lighting/mood: quiet, precise, tense final descent; gold exhaust and cyan pad glow against the dark indigo night.
Text (verbatim): "LUNAR LANDER" as the dominant title on two lines. Smaller supporting text beneath: "A PRECISION FLYING GAME FOR NETBBS".
Typography: large warm ivory geometric pixel lettering for the title; smaller restrained monospaced supporting line. Exact spelling, readable at reduced size.
Constraints: artwork representing the game concept, not a screenshot. No UI gauges, no fabricated telemetry, no browser window, no GitHub logo, no badges, no extra slogans, no watermarks, no decorative borders. Opaque background.
```
